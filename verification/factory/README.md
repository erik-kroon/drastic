# Repository factory contracts

Failure obligations before implementation: routes must not own queries, mutations or direct HTTP requests; aliasing an import or using a namespace must not bypass the route rule; type-only imports and ordinary navigation must remain allowed; the same query must remain available to the focused review and owner resolution after co-location; explicit digest binding, owner return context, browser history, unsaved input and original retry keys must survive. CI must drive a real Chromium/web/API/PostgreSQL path and fail when a journey fails. A screenshot alone or an unavailable model must not become a passing behavior claim. Evidence must exclude credentials and use only disposable synthetic books.

Presentation belongs with its feature owner. Focused-review composition, owner routing and target queries live together under `apps/web/src/components/reviews/`. Route modules parse URL state and compose those owned components. Return-context contracts remain shared because navigation crosses owners. Financial amounts, authority checks, approval binding and transaction operations remain with their existing backend owners; do not duplicate them into views or transport handlers. Small presentation details may stay local when their UX differs. Shared StyleX tokens and UI primitives remain canonical.

Critical browser CI uses the existing Vitest Chromium workflows for document owner navigation, scoped return state, unsaved invoice edits and persisted posting retry. The suite needs no model key, does not replace the separate Luna journeys and provides no Luna-verification claim. Local Luna tests continue through `bun run test:browser` and its pinned Codex proxy. The OpenAI MCP model CI gate remains disabled as requested.

The new route lint is verified through the real `lint:changed` command in an isolated synthetic repository, including negative fixtures and permitted alternatives. Repeatable lint evidence is retained in `test-results/lint-changed/results.json`. Browser evidence uses the normal source/lock/migration manifest, JSON/JUnit results, screenshots and journey receipts under `test-results/browser-critical/`.

Run `bun run test:browser:critical` after installing the pinned application Chromium (`bun run --cwd apps/api playwright install chromium`). It owns its temporary PostgreSQL/API/web instances. Run `node verification/lint-changed/run.mjs` to verify the factory lint through the same command as PR CI.
