## Adopted shape

Use mandatory adapter admission as the base, with an application-owned factory
that loads stored records and current authority. The actual dispatch owner is
responsible for using the boundary. No network call holds the database lock.
The registry belongs to each captured request and validated response.

The review added historical client/profile aliases, revision-bound counterparty
classification, embedded owner-record parties and canonical employment
restoration. It also replaced the audit UUID cursor with a monotonic sequence.
Client priority is deliberate privacy policy from the failure contract; other
ambiguous names refuse admission.

[The verification recipe](../../verification/ai-egress/README.md) describes the
operator console, payload shape, exact financial facts, typed restoration and
raw-document exception. AUT-28 introduces no domain leaf, transport catalog or
UI screen. Existing owner, authority, approval and posted-history contracts
remain the application boundary.
