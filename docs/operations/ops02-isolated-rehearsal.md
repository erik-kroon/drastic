1. Capture a reviewed source release with `bun apps/api/scripts/operations/cli.ts capture-release <absolute-reviewed-source> <new-private-release>`. 2. Add one inline synthetic evidence item, one object-backed `intake_contents` row and the matching private `v1/<bookId>/<sha256>` object bytes. 3. Run `bun apps/api/scripts/operations/cli.ts backup <private-source.json> <new-private-bundle> <private-plan.json> --confirm-local-backup`. Record `manifest.sha256` separately. Run `inspect <bundle> <recorded-sha256>`. Run `restore <private-admin.json> <bundle> <recorded-sha256> <fresh-openerp_restore_name> <new-private-output> --confirm-fresh-local-restore`. Do not reuse a failed destination. Inspect the receipt and verify `pg_database.datallowconn=false` and `datconnlimit=0` from the maintenance database. Leave the restored database fenced and stop the isolated cluster when evidence capture finishes.
