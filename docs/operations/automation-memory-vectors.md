# Independent firm-memory expectations (AUT-05)

These expectations precede implementation. Synthetic treatments are not production accounting policy. Ranking must use retained facts from the same book and a pinned algorithm; current heads cannot reconstruct a precedent.

| Synthetic history and target | Required observation |
| --- | --- |
| No eligible history for the target | Empty suggestions, zero coverage; no guessed account |
| Matching supplier and text only exist in another book | Empty suggestions; foreign decision IDs absent |
| Eligible same-book precedent, fixed inventory and target revision | Identical ranked options and history digest on repeat |
| Original treatment has a committed replacement correction | Replacement is surfaced with complete lineage; original is not offered as current treatment |
| Original treatment is reversed without replacement | Excluded and counted; not offered |
| Two identical amount/text documents, one target is the evaluation holdout | Target and its entire correction lineage excluded from its precedent set |
| A supporting decision commits after the target decision cutoff | Excluded from that target's offline evaluation |
| Consequence capture is unknown | Retained as unknown; never counted as correct or comparable |
| Same account suggestion was shown to the target reviewer | Provenance remains influenced; cannot be relabelled independent |
| Support differs in document kind or currency | Does not enter an incompatible target's options |
| Description/amount matching has no retained source facts | Explicit missing-fact exclusion, never reconstructed from current draft |
| Equal-ranked precedents arrive in different query order | Stable identity tie-break yields the same option order |

The offline artifact reports total eligible targets, targets receiving a suggestion, targets with known comparable consequences, correct consequences and unknown consequences separately. Coverage divides suggested targets by eligible targets. Consequence accuracy divides correct by known comparable targets; zero comparable targets produces an unavailable metric, not 100% accuracy. Related document/correction groups stay on one side of each temporal holdout.

Serving retains AUT-01 suggestion records with exact options, source decision IDs, provenance, consequence results, algorithm version and a history digest that includes correction and provenance inventory. A posting-sequence number alone is insufficient.
